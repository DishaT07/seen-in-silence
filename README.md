SeenInSilence 🎵
SeenInSilence is a mood-based interactive music experience inspired by concepts from Indian Knowledge Systems (IKS), particularly Navras (the nine emotional essences) and the science of music.
✨ Features
Select a mood.
Choose the intensity of the mood.
Play melodies using interactive tiles.
No prior music knowledge required.
🛠 Built With
Python
NumPy
SoundDevice
PyWebView
💡 Inspiration
The idea originated from an IKS lecture discussing Naad, Swar, frequencies, and Navras. Curiosity led me to explore how emotions and technology could come together in a simple interactive experience.
🚧 Current Status
This is Version 1. I'm continuing to improve the musical logic and understand the implementation in greater depth.
